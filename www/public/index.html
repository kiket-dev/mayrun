How it works

Local-first choke point on the write path — MCP or CLI — not another dashboard that watches after the damage.

  • Decide Repo YAML packs and rules. Deny, require approval, or allow — deterministic only.
  • Prove Hash-chained receipts with rule_id / reason. Shell-hook, CLI, or MCP — same gate.
  • Confine Optional local sandbox under Allow. Complements vendor permissions and org platforms; does not replace them.
