mayrun

Agents don’t run dangerous commands until mayrun says they may.

Install GitHub
mayrun check · run
  1. $ mayrun check 'rm -rf /' Deny dangerous-defaults · rm-rf
  2. $ mayrun run 'git push' Require approval git-safe · push
  3. $ mayrun run 'cargo test' Allow rust-dev · cargo

How it works

Local-first choke point on the write path — MCP or CLI — not another dashboard that watches after the damage.

  • Policy Repo YAML with packs and rules. Deny, require approval, or allow — deterministic only.
  • Gate Agent calls mayrun_run / CLI instead of raw shell. Overlap with host permissions is defense in depth.
  • Receipt Hash-chained JSONL: decision, rule id, reason. Free locally; CI enforcement is the Pro cliff later.
